# 🚀 Mars Mission

A browser-based survival strategy game built for the **NASA Space Apps Challenge 2026**.
Challenge: **Build a Junior Astronaut Mission Trainer**.

📊 **Presentation:** [Mars_Mission_Presentation.pdf](Mars_Mission_Presentation.pdf)

## About the game

You command a Mars base and must keep a crew of four alive for **30 days**.
The game has 3 levels (Easy, Medium, Hard). Each level has 10 days, with 2 decisions every day.
Every choice has a price, and after each decision you learn a real NASA fact.

Keep an eye on four resources:

- 💨 **Oxygen**: if it runs out, the mission fails.
- ⚡ **Power**: without it, life support stops.
- 🍎 **Food**: no food means a failed mission.
- ☢️ **Radiation**: keep it low. At 100% the mission fails.

## Features

- Live solar flare data from NASA DONKI: a stronger real flare means more radiation in the solar storm event.
- A NASA FACT after every decision.
- Dynamic weather effects: dust storms, meteors, fires and radiation glitches.
- Crew status that changes as radiation harms astronauts.
- Save and continue your mission later.
- Sound effects and ambient space music made with the Web Audio API.
- Works on desktop and mobile.

## NASA and partner data

| Resource | How we used it |
| --- | --- |
| [NASA DONKI](https://ccmc.gsfc.nasa.gov/tools/DONKI/) | Live solar flare data that changes radiation damage |
| [NASA RadLab (OSDR)](https://visualization.osdr.nasa.gov/radlab/) | Radiation facts and shielding ideas |
| [CSA Food Production](https://www.asc-csa.gc.ca/eng/) | Greenhouse, harvest and food facts |
| [NASA Mars Trek](https://trek.nasa.gov/mars/) | Inspiration for Mars surface events and rover facts |
| [NASA Open APIs](https://api.nasa.gov/) and [OSDR](https://osdr.nasa.gov/) | Live data and human health facts |

## Built with

HTML5, CSS3 and vanilla JavaScript (ES6+). No frameworks and no audio files.
